# Switchbox

A browser recreation of Switchbox, the two-player strategy game by Todd Heimarck
from COMPUTE! magazine, March 1986.

Drop balls into a pyramid of two-way switches. A ball that lands on an empty platform
stops; one that hits a trigger flips the switch and keeps falling; one that hits a
loaded switch knocks the resting ball loose, and both fall. Chain reactions score.

**Play:** open `index.html` in a browser. Keys 1-8 drop a ball, `-` passes, `+` drops
at random. Play a friend on the same screen or the computer (Easy, Medium, Hard).

**Options:** pass limit, lowball, custom goals and exit values, sound.

**Develop:** see `CLAUDE.md` for structure, commands, and decisions made so far, and
`docs/next-features.md` for the approved next batch of work.
